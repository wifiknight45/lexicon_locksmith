How this Wordle helper helps

Stuck mid-puzzle on NYT Wordle? Instead of guessing randomly, feed Lexicon Locksmith each word you already tried and the green / yellow / gray pattern you saw. It filters a local five-letter word list so you can see which combinations remain — a practical Wordle solver workflow that keeps the puzzle yours.

G
G — Green Letter is correct and in the right position.
Y
Y — Yellow Letter is in the word, but not in that position.
R
R — Gray / absent Letter is not in the word (or is an excess duplicate).

What you get

  • Wordle filter / combinations finder — eliminate impossible words after every guess.
  • Letter-frequency ranking — the CLI ranks remaining candidates to suggest informative next plays.
  • Colorblind Wordle support — high-contrast and symbol modes tuned for deutanopia, not color alone.
  • Offline & private — runs locally from a word list on disk; no account and no answer feed.

Built for colorblind Wordle players

Many Wordle helpers assume green vs yellow is obvious. Lexicon Locksmith’s CLI lets you pick a display mode at startup:

  1. Standard — blue / magenta / gray with symbols for redundant encoding.
  2. High contrast — stronger separation for low-vision and busy screens.
  3. Colors only — if you prefer no symbols.

Modes are designed with deutanopia (common red–green color vision deficiency) in mind, so a Wordle colorblind workflow is a first-class feature — not an afterthought.

    Install & run the Wordle CLI

    Requirements: Python 3.7+. No third-party packages.

    Clone the repository

    git clone https://github.com/wifiknight45/lexicon_locksmith.git
cd lexicon_locksmith

    Start the solver

    Any of these run the same canonical helper:

    python wordle_combo_finder.py

    Then pick a display mode, enter each guess + G/Y/R feedback, and use commands like done, undo, export, legend, or quit.

    Frequently asked questions

    What is Lexicon Locksmith?

    A free open-source Wordle helper (useful for NYT Wordle) that filters remaining candidate words from your guesses and green/yellow/gray (G/Y/R) feedback, with letter-frequency ranking and colorblind-friendly CLI modes.

    Is this an official New York Times Wordle tool?

    No. It is an independent community project and is not affiliated with, endorsed by, or sponsored by The New York Times or Wordle.

    Does this Wordle solver spoil today’s answer?

    No. It never fetches or displays official daily answers. It only filters a local word list based on the guesses and feedback you enter.

    How does the G/Y/R Wordle filter work?

    After each guess, enter five characters: G (correct letter and position), Y (in the word, wrong position), R (not in the word, or excess duplicate). Words that contradict the feedback are removed.

    Is Lexicon Locksmith colorblind-friendly?

    Yes. The CLI offers high-contrast and symbol-based modes designed with deutanopia in mind, so you are not relying on green vs yellow alone.

    How do I run the Wordle helper on my computer?

    Clone the GitHub repo, then run python wordle_combo_finder.py or python -m lexicon_locksmith. Python 3.7+; no pip dependencies.
