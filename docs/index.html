    FAQ

    What is Lexicon Locksmith?

    Open-source Wordle helper: filter candidates from G/Y/R feedback. CLI ranking + colorblind modes.

    Is this an official New York Times Wordle tool?

    No. Not affiliated with The New York Times or Wordle.

    Does this Wordle solver spoil today’s answer?

    No. It never fetches daily answers.

    How does the G/Y/R Wordle filter work?

    G right spot, Y wrong spot, R absent. Contradictions removed.

    Is Lexicon Locksmith colorblind-friendly?

    Yes. CLI high-contrast and symbol modes (deutanopia).

    How do I run the Wordle helper on my computer?

    Clone; run python wordle_combo_finder.py or python -m lexicon_locksmith.
