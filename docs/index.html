    FAQ

    What is Lexicon Locksmith?

    A free open-source Wordle helper that filters remaining candidates from your guesses and G/Y/R feedback, with letter-frequency ranking and colorblind CLI modes.

    Is this an official New York Times Wordle tool?

    No. Independent community project — not affiliated with The New York Times or Wordle.

    Does this Wordle solver spoil today’s answer?

    No. It never fetches daily answers; it only filters a local word list from feedback you enter.

    How does the G/Y/R Wordle filter work?

    G = correct position, Y = wrong position, R = absent. Candidates that contradict the pattern are removed.

    Is Lexicon Locksmith colorblind-friendly?

    Yes — CLI high-contrast and symbol modes designed with deutanopia in mind.

    How do I run the Wordle helper on my computer?

    Clone the repo, then python wordle_combo_finder.py or python -m lexicon_locksmith.
